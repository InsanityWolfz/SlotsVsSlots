# Legacy balance harnesses (pre-Tuesday rework)

These drove the "commit" drafting policy around FULL SETS and TIER II charms, which the 2026-09-27 rework
removed. They no longer run against the current rules and are kept only as a record of how the old
numbers in `loop/STATE.md` (iterations 6-23) were measured.

Use `tools/balance/tuesday.ts` (the official greedy sim per slot machine: WHITE and GREEN, the Dealer,
act 3), `diag.ts` (bare machines vs act 1) and `calib.ts` (measured late-run damage) instead.
