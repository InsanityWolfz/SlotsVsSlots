# Slots vs. Slots

An 8-bit roguelike where two slot machines fight. You don't aim, hold or nudge: the reels decide each fight, and
the enemy cheats by writing on your machine. Your choices come between fights: which enemy to take at a fork,
which card to draft, what to buy at the Cashier, and which Charms and relics to build around.

**Play:** https://insanitywolfz.github.io/SlotsVsSlots/

What's in the game: [docs/GAME.md](docs/GAME.md). What's next: [docs/ROADMAP.md](docs/ROADMAP.md).

## Develop

```bash
npm install
npm run dev            # http://localhost:5173 (window.dbg helpers + TUNE panel)
npm test               # rules, invariants, saves
npm run build          # typecheck + public build -> dist/ (no dev tools)
npm run build:playtest # build with the debug helpers -> playtest-build/
npm run build:steam    # desktop build (see desktop/README.md)
```

## Hosting

`.github/workflows/deploy.yml` tests, builds and publishes to GitHub Pages on every push to `main`
(repo Settings → Pages → Source: GitHub Actions). Paths are relative, so `dist/` also works as-is on itch.io,
Netlify or any static host.

## Layout

```
src/core/     pure rules engine: deterministic, no DOM (fight, run, enemies, relics, stakes, saves)
src/present/  presentation: the Director plays engine events back with the juice
src/ui/       menus, run screens, tutorial coach
src/render/   pixel art data (generated by tools/build-art.mjs), sprites, pixel font
src/audio/    procedural Web Audio synth, sound effects, code-composed music
src/net/      online leaderboards (Supabase; schema in supabase/)
src/sim/      headless bot + simulator (being replaced)
tools/        art pipeline, sims, content audit, Steam helpers, screenshot and music renderers
desktop/      Electron + Steamworks wrapper
docs/         the game today, the roadmap, the juice rules
```
