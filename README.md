# Slot vs Slot

A prototype built to answer one question: is turn-based combat between two slot machines fun?
The hero's machine (Sword / Shield / Bolt) fights the Slime King's machine (Sword / Shield / Slime).
Rules and design rationale are in [DEMO_PLAN.md](DEMO_PLAN.md). The feel spec is
[JUICE_REFERENCE.md](JUICE_REFERENCE.md).

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # rules + log tests
npm run sim        # headless balance sim (20k fights per variant)
npm run build      # typecheck + production build
```

## Controls

| Key | Action |
|---|---|
| Space | Start fight / Spin (manual mode) / skip the current presentation |
| Click anywhere | Skip the current presentation |
| A | Toggle auto-spin |
| 1 / 2 / 3 | 1× / 2× / 4× speed |
| R | Restart fight |
| M | Mute |
| T or \` | Tuning panel (every rule number, seed, juice toggles, force next spin, in-browser sim) |
| L | Combat log (filter, copy JSON, download CSV) |

Tuning and preferences are saved in localStorage.

## Layout

```
src/core/     pure rules engine: deterministic, no DOM (config, rng, strips, scoring, fight, stats, log)
src/sim/      headless simulator (used by `npm run sim` and the tuning panel)
src/present/  presentation: game clock (speed/hitstop/skip), camera juice, reels, machines, HUD, fx, director
src/render/   pixel art data (generated by tools/build-art.mjs), sprite cache, pixel font, background
src/audio/    procedural Web Audio synth + every named sound
src/ui/       canvas buttons, recap screen, DOM tuning panel + combat log
tools/        art generator + art preview page
```

For each turn, `Fight.step()` decides the entire outcome up front and returns an ordered event
list. The `Director` then plays those events back as animation. Game state never waits on
animation, and the display keeps its own copy of the reel strips, which only catches up when the
animation lands.

In dev builds, `window.dbg` has frame-stepping helpers for QA:
`dbg.fight(['bolt','bolt','bolt'])`, `await dbg.until('specialFire')`, `await dbg.adv(0.3)`.

Art: edit `tools/build-art.mjs` and run `node tools/build-art.mjs`. Don't hand-edit `src/render/spriteData.ts`.
